# Boutik Safe

Structure simplifiée pour GitHub et Vercel :

- `index.html` : page de présentation et choix de plateforme
- `application.html` : application Web principale utilisable sur PC et navigateur
- `downloads/Boutik-Safe.apk` : installation Android
- `assets/icon.png` : icône

## Utilisation

- Android : cliquez sur le téléchargement Android pour récupérer l'APK.
- PC : cliquez sur « Utiliser sur PC » pour ouvrir `application.html` dans le navigateur.

## Déploiement

Téléversez tout le contenu de ce dossier en conservant exactement cette structure. Ne remplacez pas `application.html` par `index.html`.
