# Boutik Safe
Développé par Eternal.

## Fichiers principaux
- index.html : présentation complète et choix Android / PC
- application.html : application Web
- app-release.apk : APK Android signée
- manifest.json + service-worker.js : installation PWA et cache hors ligne
- images/ : visuels locaux fixes des différentes catégories

Les visuels sont intégrés localement pour éviter les changements aléatoires liés à Internet.
