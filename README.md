# Boutik Safe

## Structure

- `index.html` : page de présentation
- `application.html` : application Web pour PC et navigateur
- `app-release.apk` : application Android
- `icon.png` : icône

## Utilisation

- Bouton Android → `app-release.apk`
- Bouton PC → `application.html`

Tous les fichiers sont directement à la racine pour éviter les problèmes de téléversement des sous-dossiers.
